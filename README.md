# ✈️ Google Flights 機票價格自動監測系統

## 📌 解決痛點與專案目標

在規劃自助旅行或尋找機票時，旅客常面臨的痛點：
**票價浮動頻繁、手動重複比對各航線耗時**，且錯失特價機票的黃金時機。

**本專案目標：** 建立一套自動化的 Google Flights 智慧監控引擎，**自動抓取指定航線的最新票價與航班資訊**（支援最低價與最佳方案雙軌並行解析），並透過 Discord Webhook 即時發送警報，同步記錄歷史數據至 CSV/JSON 以供後續數據分析與視覺化應用。

---

## 🛠️ 技術棧

- **自動化爬蟲與瀏覽器控制：** `Python 3`, `Playwright (Chromium)`, `BeautifulSoup`
- **資料處理與結構化：** `Pandas`, `NumPy`, `JSON`
- **雲端自動化與排程：** `GitHub Actions` (支援一天執行一次等定時自動化任務)
- **即時通知與監控機制：** `Discord Webhook API`, 內建重試與異常攔截機制
- **自動化執行與日誌管理：** 跨次追加日誌 (`Logging`), 支援批次冷卻與防封鎖策略 (`Jitter`)

---

## 🔍 核心功能與資料分析洞察

### 1. 雙軌方案深度解析（最低價 vs. 最佳方案）
- **智慧方案比對**：系統針對每筆查詢同時撈取「絕對最低價方案」與「最佳綜合評估方案」。
- **異同智慧識別**：若最低價與最佳方案內容完全一致，自動優化記錄標記，避免數據冗餘。

### 2. 航班與行李額度完整封裝
- **航班細節透視**：精準擷取去回程之航線、航班編號、起降時間、飛行總時數與轉機次數。
- **行李政策解析**：自動向下挖掘航班詳細資料，精準記錄免費隨身與託運行李額度（如件數限制），免去手動點擊確認的麻煩。

---

## ⚙️ 自動化流程與監控機制

本專案建置了一套穩健的自動化排程與監控架構，從雲端排程觸發、網頁動態解析、例外重試到 Webhook 即時通知，流程說明如下：

### 1. 雲端定時排程與防封鎖策略
- 透過 `.github/workflows` 實現雲端自動化排程（如設定一天執行一次），自動載入 `config.json` 中的航線設定（如 KMQ、BUD 等目的地）。
- 內建批次大小控制 (`batch_size`)、冷卻暫停與隨機延遲 (`Jitter`)，有效模擬真人操作、降低被目標網站阻擋的風險。

### 2. 例外處理與 Discord 即時警報
- 內建最大重試次數與延遲機制，當網頁載入逾時或遭遇系統錯誤時自動重新發起請求。
- 若連續重試失敗，將透過 Webhook 即時推播錯誤訊息至 Discord 頻道，確保監控不斷線。

### 3. 縱向分段追加與歷史數據沉澱
- 支援 CSV (`.csv`) 與 JSON (`.json`) 雙格式歷史紀錄自動擴充。
- 採用縱向分段追加設計（將最低價與最佳方案獨立為資料列），方便後續匯入 BI 工具或進行長期的機票價格走勢與趨勢分析。
